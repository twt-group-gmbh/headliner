Overrides the partial of fluid_styled_content. It is a copy of it, except that the tag of the header and subheader comes from the fields "header_tag" and "subheader_tag", and the layout only decides the CSS class (ce-headline-layout-N); the subheader has the layout of its header. The subheader tag can be switched off in the site settings (headliner.subheader.enabled); then the subheader follows the header tag. {record -> f:render.text(field: 'header', optional: true)} {record -> f:render.text(field: 'subheader', optional: true)}
