The same as the block "cards", but the ViewHelper gets the record and reads the tag, the layout and the mark for the page module from it: no tag="...", layout="..." or edit="..." anywhere. A card without a tag of its own is one level below the header of the element (parent="{data}"), not an h2 under whatever the header is. There is no headliner:headline.children around a card either: the records tell the page module themselves which record a heading in a rich text is in.
{data -> f:render.text(field: 'header')} {header}
{card -> f:render.text(field: 'title')} {card -> f:render.text(field: 'text')}
